# BLETHLAND

BLETHの公式ホームページ `BLETHLAND` を、2004年8月29日時点のサイトが削除されず公開され続けている見え方で整えるプロジェクトです。

## 公開サイト

- BLETHLAND: https://chiahinado.jp/bleth/
- GitHub Pages配信元: `main` ブランチの `/docs`

## ディレクトリ

- `blethland/`: 旧サイト原本。読み取り専用かつGit管理対象外
- `docs/`: GitHub Pagesで公開する新サイト
- `planning/`: 文言監査、実装用コピー、サイトマップ

## ローカルプレビュー

```sh
python3 -m http.server 8000 --directory docs
```

ブラウザで `http://localhost:8000/` を開きます。

## LIVEページの再生成

年表データや詳細ページを更新した後、次のコマンドで公開HTMLを再生成します。

```sh
node tools/build_live_archive.mjs
```

## MUSIC・EXTRAS・お化け屋敷・サイドゲート・404の再生成

楽曲、歌詞、EXTRAS、お化け屋敷、ファンクラブ、リンク、404ページを更新した後、次のコマンドで公開HTMLを再生成します。旧 `/shows/` は `/live/` への転送ページとして同時に生成されます。

```sh
node tools/build_park_sections.mjs
```

## 公開方針

- BLETHは現在も活動しているバンドとして表現する
- BLETHの楽曲、歌詞、音源は公開可能として扱う
- メンバー紹介は1ページに統合し、私的情報と当時の悪ノリを掲載しない
- お化け屋敷は単独ページで `現在閉鎖中` と表示し、人物写真3点は公開用ディレクトリへコピーしない
- それ以外の旧サイト内写真は原則掲載可能とし、公開用コピーからEXIFを除去する
- 旧フォーム、BBS、外部CGI、古い連絡先は再公開しない
- GitHub Pagesの `/bleth/` 配下で動くよう、内部参照は相対パスを基本とする

## デザイン原則

- トップは背景、現行BLETHLANDロゴ、透過アトラクションを別レイヤーで構成する
- トップは遊園地マップ内のリンクだけで構成し、重複する下部リンクカードやフッターを置かない
- ホバー時は対象アトラクション画像だけを明るくし、四角い枠を表示しない
- マップ左上のラベルは表示せず、最終更新日は右上へHTMLテキストとして重ねる
- 各ページは「同じ遊園地にある別のアトラクション」として設計する
- 明るい空、クリーム色の園内、太い色枠、立体的な看板UI、手描きイラストの質感を共通言語にする
- ジェットコースターの `LIVE` に今後の予定とこれまでのライブを統合し、バイキングを `EXTRAS` にする
- お化け屋敷は単独アトラクションとしてトップからリンクする
- サイト内では後世のアーカイブ、復刻、再構築として説明せず、2004年の公式サイトとして現在形で案内する
- メンバー紹介では写真を掲載せず、各メンバーの担当と名前だけを表示する
- 各ページのヒーロータイトルは、背景イラストを隠さないコンパクトなサイズに統一する
