# BLETHLAND

BLETHの旧公式ホームページ `BLETHLAND` を、遊園地の世界観を受け継ぎながら現代的に再構築するプロジェクトです。

## 公開サイト

- BLETHLAND: https://chiahinado.jp/bleth/
- GitHub Pages配信元: `main` ブランチの `/docs`

## ディレクトリ

- `blethland/`: 旧サイト原本。読み取り専用かつGit管理対象外
- `docs/`: GitHub Pagesで公開する新サイト
- `planning/`: 文言監査、実装用コピー、サイトマップ

## ローカルプレビュー

```sh
python3 -m http.server 8000 --directory docs
```

ブラウザで `http://localhost:8000/` を開きます。

## LIVE ARCHIVEの再生成

年表データや詳細ページを更新した後、次のコマンドで公開HTMLを再生成します。

```sh
node tools/build_live_archive.mjs
```

## MUSIC・SHOWS・EXTRAS・サイドゲート・404の再生成

楽曲、公演記録、特別展示、ファンクラブ、リンク資料、404ページを更新した後、次のコマンドで公開HTMLを再生成します。

```sh
node tools/build_park_sections.mjs
```

## 公開方針

- BLETHは現在も活動しているバンドとして表現する
- BLETHの楽曲と音源は公開可能として扱い、歌詞は掲載しない
- メンバー紹介は1ページに統合し、私的情報と当時の悪ノリを掲載しない
- お化け屋敷の人物写真3点は公開用ディレクトリへコピーしない
- それ以外の旧サイト内写真は原則掲載可能とし、公開用コピーからEXIFを除去する
- 旧フォーム、BBS、外部CGI、古い連絡先は再公開しない
- GitHub Pagesの `/bleth/` 配下で動くよう、内部参照は相対パスを基本とする

## デザイン原則

- トップの遊園地マップをBLETHLAND全体の基準ビジュアルとする
- トップは遊園地マップ内のリンクだけで構成し、重複する下部リンクカードやホバー演出を置かない
- マップ左上のアーカイブラベルは表示せず、最終更新日は右上へHTMLテキストとして重ねる
- 各ページは「同じ遊園地にある別のアトラクション」として設計する
- 明るい空、クリーム色の園内、太い色枠、立体的な看板UI、手描きイラストの質感を共通言語にする
- `LIVE ARCHIVE` は青、`MEMBERS` は緑、`MUSIC` はピンク、`SHOWS` はオレンジ、`EXTRAS` は紫・緑を主なアトラクションカラーにする
- 写真アーカイブの可読性は保ちつつ、暗い汎用アーカイブUIには戻さない
- メンバー紹介では写真を掲載せず、各メンバーの担当と名前だけを表示する
- 各ページのヒーロータイトルは、背景イラストを隠さないコンパクトなサイズに統一する
