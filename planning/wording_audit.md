# BLETHLAND 文言改訂監査

- 作成日: 2026-08-28
- 対象: `blethland/` 内の HTML / HTM 70ページ
- 状態: 実装前の編集方針
- 原則: `blethland/` は読み取り専用の原本として保持し、この文書では削除・修正しない

## 1. 確定した基本方針

- サイト名の正式表記は、スペースなしの **`BLETHLAND`** とする。
- BLETHは現在も活動しているロックバンドとして扱う。
- バンドそのものを「活動した」「活動していた」「解散した」と過去形で説明しない。
- 基本紹介は **「東海地方を拠点に活動しているロックバンド BLETH」** とする。
- サイトは歴史アーカイブだが、「再結成」「再始動」「再開園」などの新しい物語は加えない。
- 2004年当時のホームページとしての内容・世界観・サイトマップを保ち、表現、可読性、安全性、操作性を現代化する。
- 過去の公演、当時の告知、撮影時点など、歴史上の出来事には必要に応じて過去時制を使う。

## 2. 編集レイヤー

### A. 現代語へ編集する

ナビゲーション、見出し、ページ説明、操作案内、メタ情報は全面的に整える。

- 不自然な英語を直す。
- `!!`、`!?`、`・・・`、`。。。`、過剰な記号を減らす。
- `check`、`Back`、`Eメール`など、日本語の中に唐突に入る英語を整理する。
- 現在も募集・販売・受付しているように見える表現は、確認できるまで使わない。
- 文体を「である調」と「です・ます調」で混在させない。

### B. 事実を保って再編集する

ライブ日程、会場、出演者、価格、活動記録などは事実を変えず、読みやすいアーカイブ文へ整える。

- 日付、会場名、曲名、クレジット、固有名詞は原文と照合する。
- 当時価格には必要に応じて「当時」を付ける。
- 現在のイベント案内や販売情報と誤認されるCTAは置かない。
- 事実関係が不明な箇所は推測で補わず、確認待ちにする。

### C. 一次資料として原文を残す

歌詞、作詞作曲クレジット、メンバー本人のコメント、当時のライブメッセージは、原則として原文を残す。

- 現代の案内文と混同しないよう、「当時のコメント」などの見出しを付ける。
- 明白な文字化けだけを復元する。
- 誤字を直す場合は内容を変えない。
- BLETHの歌詞と音源は公開可能として扱う。旧音源は現代ブラウザで再生できる形式へ変換する。

### D. 安全な展示へ再構築する

外部CGI、旧メール、BBS、個人情報送信フォーム、アクセス解析は接続しない。

- クイズ、おみくじ、占いはブラウザ内だけで完結させる。
- 入力内容を保存・送信しない。
- 旧ファンクラブフォームは稼働させず、歴史展示として再構成する。
- 旧リンク先は自動的に引き継がず、必要なものだけ現在の所有者と内容を確認する。

## 4. 表記ルール

- 英語の主要ナビゲーションは大文字で統一する。
- 日本語本文では `LIVE` ではなく `ライブ` を基本とする。
- バンド名、曲名、イベント名など正式名称は原表記を尊重する。
- 日付は一覧では `2004.08.29`、本文では `2004年8月29日` を使う。
- 半角カナは使わない。
- 感嘆符は原則1個までとし、UI説明では使わない。
- 顔文字、矢印の連打、過剰な伸ばし文字は、一次資料以外では使わない。
- `詳細はこちら` だけのリンクを避け、リンク先が分かる名称にする。
- `Back` は廃止し、`一覧へ戻る` またはパンくずナビゲーションを使う。
- `Download` は内容と形式を明記し、公開可能な音源がある場合だけ表示する。
