# BLETHLAND サイトマップ

- 更新日: 2026-08-29
- 公開先: GitHub Pages `/bleth/`
- 公開ファイル: `docs/`
- 旧サイト原本: `blethland/`（読み取り専用・Git管理対象外）

## 1. サイトの前提

- 2004年8月29日時点のBLETHLANDが削除されず、そのまま公開され続けている体裁にする。
- 後世のアーカイブ、復刻、再構築として説明しない。
- BLETHは「東海地方を拠点に活動しているロックバンド」と現在形で表現する。
- トップは遊園地マップ内のアトラクションだけで移動できる構成にする。
- フッターと、トップ下部の重複リンクカードは置かない。

## 2. トップのアトラクション

| 施設 | 表示 | 移動先 |
|---|---|---|
| ジェットコースター | `LIVE / ライブ情報` | `/live/` |
| 観覧車 | `MEMBERS / プロフィール` | `/members/` |
| メリーゴーラウンド | `MUSIC / 楽曲・歌詞・音源` | `/music/` |
| バイキング | `EXTRAS / お楽しみ` | `/extras/` |
| お化け屋敷 | `HAUNTED HOUSE / お化け屋敷` | `/haunted-house/` |
| ピンクの看板 | `I LOVE BLETH / FAN CLUB` | `/fanclub/` |
| 青の看板 | `LINKS / 関連リンク` | `/links/` |

トップ画像は次のレイヤーに分ける。

1. 空、街並み、園路、植栽を描いた背景画像
2. 現在のBLETHLANDロゴ画像
3. 透過された7つのアトラクション画像
4. HTMLで表示する各施設名、キャプション、`LAST UPDATED 2004.08.29`

ホバー時は対象アトラクション画像だけを明るくする。四角い白枠は表示しない。

## 4. LIVE統合

旧LIVEアーカイブと旧SHOWSは `/live/` に統合する。

1. `NEXT LIVE / これからの予定`
   - `現在、ライブの予定はありません。`
2. `LIVE HISTORY / これまでのライブ`
   - 1999年から2004年までの27公演
   - 詳細資料のある16公演だけ個別ページへリンク

旧 `/shows/` は重複内容を表示せず、`/live/` へ転送する。

## 5. EXTRASとお化け屋敷

バイキングの `/extras/` には次の3企画を表示する。

- `BLETH QUIZ / BLETHクイズ`
- `BLETHLAND FORTUNE / おみくじ`
- `SPECIAL EXHIBIT / GLAYコピーバンド企画`

3企画はすべて `現在閉鎖中` とし、個別ページへのリンクを置かない。

お化け屋敷はEXTRASから分離する。トップから `/haunted-house/` へ入り、アトラクションイラストと `現在閉鎖中` だけを表示する。

## 6. メンバーとプライバシー

- メンバーは `/members/` の1ページに統合する。
- 写真と紹介文は掲載せず、担当と名前だけを表示する。
- 誕生日、血液型、身体情報、住所、勤務先、家族、恋愛などの私的情報は掲載しない。
- お化け屋敷の人物写真 `ghost01.jpg`〜`ghost03.jpg` は公開しない。
- これら3点は加工、サムネイル、生成AIの参照にも使用しない。

## 7. 公開素材

| 素材 | 方針 |
|---|---|
| 現在のBLETHLANDロゴ | トップ用画像として継続使用 |
| トップ背景 | アトラクションを含まない新規画像 |
| トップ施設 | 透過WebPとして個別配置 |
| EXTRAS施設 | 同一画風のWebPを各カードに配置 |
| ライブ写真 | 公開可能なものを掲載し、EXIFを除去 |
| 歌詞・音源 | 歌詞9曲、公開可能なMP3音源を掲載 |
| 外部CGI、BBS、旧メール | 再公開しない |
| 個人情報を含むフォーム | 再公開しない |

## 8. 生成コマンド

```sh
node tools/build_live_archive.mjs
node tools/build_park_sections.mjs
```

`docs/` には公開可能と判断したファイルだけを置き、旧サイト原本から一括コピーしない。
