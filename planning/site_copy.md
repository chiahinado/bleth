# BLETHLAND 実装用サイトコピー

- 作成日: 2026-08-28
- 用途: トップページ、共通ナビゲーション、各セクション入口の実装用文言
- 前提: `planning/wording_audit.md` の編集方針に準拠
- 状態: 旧コピー案（2026-08-29の現行ルールが最優先）

## 0. 現行コピー・デザインルール（最優先）

BLETHLANDは、ページの意図や保存経緯を逐一説明しない。普通のロックバンドのホームページとして、見出し、固有名、日付、会場、クレジット、音源、写真などの実データで成立させる。

- ヒーローは英字タイトル1つと短いアトラクション番号だけにする。
- タイトル直後に、日本語で同じ意味を言い換えるリード文を置かない。
- 「〜を紹介します」「アーカイブです」「歴史展示です」「当時の〜」「このページは〜」「ご利用いただけません」などの説明口調を表示しない。
- 共通ヘッダーの文字ロゴは BLETHLAND だけにする。
- LIVE ARCHIVE は固有のセクション名として維持する。それ以外のメタなアーカイブ表現は画面へ追加しない。
- MUSICは TRACKS / CREDITS / AUDIO / COMMENT で構成する。歌詞を載せず、非掲載であることも説明しない。
- MEMBERSは名前と担当だけを表示する。
- SHOWSは NEXT SHOW / NO SCHEDULE と年代別データだけを表示する。
- EXTRASは4コンテンツの名前と CLOSED だけを表示し、リンクを置かない。個別URLは CLOSED の一語だけで閉鎖を示す。
- I LOVE BLETHは BENEFITS / ENTRY、LINKSは NO LINKS / SITE BANNERS だけで構成する。
- 一覧下部の「トップへ戻る」、全ページ共通フッター、重複する案内カードは置かない。
- 太い囲み枠と大きな立体影を多用しない。白地、細い罫線、セクションカラーのアクセント、短い英字ラベルで統一する。
- 下層ページのタイトルはPC・スマホともコンパクトにし、背景のアトラクションを見せる。

以下の各節は制作経緯として残す旧コピー案であり、表示文言には使用しない。現行HTMLと tools/build_park_sections.mjs、tools/build_live_archive.mjs を実装上の正とする。

## 1. コピーの軸

BLETHLANDは、2004年当時のホームページの構成と遊園地の世界観を受け継ぐ、BLETHのオフィシャルアーカイブである。

サイト内では、BLETHを現在も活動しているバンドとして扱う。バンドの紹介に過去形を使わず、過去時制は公演日、掲載時点、当時の企画など、歴史上の出来事にだけ使用する。

遊園地らしい楽しさは、アトラクション名、案内サイン、イラストで表現する。本文では過剰な感嘆符、内輪向けの呼びかけ、不自然な英語を避け、短く明快に案内する。

トップの遊園地マップをBLETHLAND全体の基準ビジュアルとする。各ページは同じ遊園地内の別アトラクションとして、明るい配色、太い色枠、立体的な看板UI、手描きイラストの質感を引き継ぐ。写真や年表を扱うページでも、暗い汎用アーカイブUIにはしない。

## 3. 共通ヘッダー

### ロゴ

```text
BLETHLAND
THE OFFICIAL ARCHIVE OF BLETH
```

ロゴのリンク先は常にトップページとする。ロゴ付近に `HOME` を重ねて表示しない。

### グローバルナビゲーション

| 英語見出し | 日本語補助表記 | 移動先 |
|---|---|---|
| `LIVE ARCHIVE` | ライブ・写真 | ライブ年表 |
| `MEMBERS` | プロフィール | メンバー一覧 |
| `MUSIC` | 楽曲・クレジット・音源 | 楽曲一覧 |
| `SHOWS` | 公演記録 | 公演情報の記録 |
| `EXTRAS` | 特別展示 | クイズ・おみくじ・企画 |

### その他のナビゲーション

| 英語見出し | 日本語補助表記 |
|---|---|
| `I LOVE BLETH` | FAN CLUB ARCHIVE |
| `LINKS` | 関連リンク |

スマートフォンのメニューボタンは `MENU`、閉じるボタンは `CLOSE` とする。アイコンだけにせず、文字ラベルを併記する。

## 4. トップページ

トップは遊園地マップだけで構成し、マップ内の各アトラクションをリンクとして使用する。重複するウェルカムカード、アトラクションカード、サブコンテンツカードは置かない。ホットスポットには発光、白枠、ツールチップなどのマウスオン演出を付けない。

画像左上の `HISTORICAL ARCHIVE` は表示しない。右上には画像内文字を使わず、次の文字列をHTMLテキストとして重ねる。

```text
LAST UPDATED 2004.08.29
```

下層ページのヒーロータイトルは、背景のアトラクションが見えるコンパクトなサイズと高さで統一する。

## 5. LIVE ARCHIVE

ページ見出し:

```text
LIVE ARCHIVE
ライブ・写真
```

リード文:

```text
BLETHのライブを、日付・会場・写真とともにたどるアーカイブです。
```

一覧の表示項目:

- 日付
- 公演名
- 会場
- 写真の有無

操作ラベル:

- `ライブの詳細を見る`
- `写真を見る`
- `前のライブ`
- `次のライブ`
- `LIVE ARCHIVEへ戻る`

当時のメンバーコメントには、次の見出しを付ける。

```text
COMMENT FROM THE ARCHIVE
当時のコメント
```

## 6. MEMBERS

ページ見出し:

```text
MEMBERS
プロフィール
```

リード文:

```text
BLETHのメンバーを、担当と名前で紹介します。
```

全メンバーをこの1ページにまとめ、個別プロフィールページは作らない。カードまたはページ内アンカーで、次の項目だけを表示する。

プロフィールカードの項目:

- 名前
- パート

メンバー写真と紹介文は掲載しない。

操作ラベル:

- `MEMBERSへ戻る`

誕生日、血液型、身長、体重、足のサイズ、視力、愛車、住所・地域、勤務先、家族・ペット、恋愛、私生活上の好みは掲載しない。当時の悪ノリや内輪向けの冗談も削除する。

人数は、旧トップの「6人組」と現存する5人分のプロフィールの不一致が解決するまで本文に記載しない。

## 7. MUSIC

ページ見出し:

```text
MUSIC
楽曲・クレジット・音源
```

リード文:

```text
BLETHの楽曲を、クレジット、当時のコメントとともに紹介します。
公開可能な音源がある楽曲は、このページで再生できます。
```

楽曲カードの項目:

- 曲名
- 作詞・作曲クレジット
- 音源
- 当時のコメント

操作ラベル:

- `楽曲の詳細を見る`
- `音源を再生`
- `一時停止`
- `前の楽曲`
- `次の楽曲`
- `MUSICへ戻る`

音源を掲載しない場合:

```text
この楽曲の音源は現在公開していません。
```

`ORIGINAL SONGS`、`オリジナル曲`、`試聴するにはRealPlayerが必要です`は使用しない。


```text
このコンテンツは現在ご利用いただけません。
```

### お化け屋敷の画像方針

旧ページ内の人物写真 `web_illust_jpg/ghost01.jpg`、`ghost02.jpg`、`ghost03.jpg` は、プライバシー保護のため非公開とする。公開ディレクトリへコピーせず、サムネイル、ぼかし、切り抜き、生成AIへの参照にも使用しない。

お化け屋敷は、新しく制作する背景、イラスト、文字演出だけで再構築する。旧 `ghost.gif`、`ghost_t.gif` などの装飾画像も直接流用せず、新しい世界観へ描き直す。

お化け屋敷の案内文では、非公開写真が存在することを説明しない。

```text
BLETHLANDで案内していたファンクラブ「I LOVE BLETH」の資料を展示しています。
```

## 11. LINKS

ページ見出し:

```text
LINKS
関連リンク
```

リード文:

```text
BLETHに関連する、現在確認できるリンクを掲載します。
```

リンクカードの項目:

- サイト名
- 関係・説明
- 外部サイトであることの表示

操作ラベル: `外部サイトを開く`

外部リンク注記:

```text
外部サイトの内容は、BLETHLANDが管理するものではありません。
```

確認できるリンクがない場合:

```text
現在掲載している関連リンクはありません。
```

旧リンク集の紹介文、管理人名、募集情報、リンク切れURLは自動的に再掲載しない。

## 13. 共通UI文言

| 用途 | 使用する文言 | 使用しない文言 |

| 一覧へ戻る | `一覧へ戻る`、`MUSICへ戻る`など | `Back`、`back` |

| 音源 | `音源を再生` | `BLETHの歌を聴こう!!` |
| メニュー | `MENU` | `INFORMATION` |

## 15. 実装時の確認事項

初期実装では、次の未確定情報をコピーに含めない。

1. メンバーの人数。
2. CDの現在価格と購入方法。
3. 現在のライブ予定とチケット販売。
4. ファンクラブの現在の運営状況。
5. 未確認の外部リンク。
6. 公開許可を確認していない第三者情報。BLETHの音源は公開可能、歌詞は非掲載。

これらが確認できた場合も、歴史資料と現在の案内を同じ表示領域に混在させない。

お化け屋敷の人物写真以外の旧サイト内写真は原則掲載可能とする。ただし、公開用に複製する際はEXIFなどの付帯メタデータを除去する。
