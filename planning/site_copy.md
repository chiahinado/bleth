# BLETHLAND 実装用サイトコピー

- 作成日: 2026-08-28
- 用途: トップページ、共通ナビゲーション、各セクション入口の実装用文言
- 前提: `planning/wording_audit.md` の編集方針に準拠
- 状態: 初期実装に使用可能

## 1. コピーの軸

BLETHLANDは、2004年8月29日時点で更新が止まり、そのまま公開され続けているBLETHの公式ホームページとして扱う。

サイト内では、後世のアーカイブ、歴史展示、復刻、再構築として説明しない。BLETHを活動しているバンドとして扱い、案内文は2004年のサイト運営時点の現在形で書く。終了済みの公演そのものを説明する場合だけ過去時制を使用する。

遊園地らしい楽しさは、アトラクション名、案内サイン、イラストで表現する。本文では過剰な感嘆符、内輪向けの呼びかけ、不自然な英語を避け、短く明快に案内する。

トップの遊園地マップをBLETHLAND全体の基準ビジュアルとする。各ページは同じ遊園地内の別アトラクションとして、明るい配色、太い色枠、立体的な看板UI、手描きイラストの質感を引き継ぐ。

## 3. 共通ヘッダー

### ロゴ

```text
BLETHLAND
THE OFFICIAL SITE OF BLETH
```

ロゴのリンク先は常にトップページとする。ロゴ付近に `HOME` を重ねて表示しない。

### グローバルナビゲーション

| 英語見出し | 日本語補助表記 | 移動先 |
|---|---|---|
| `LIVE` | ライブ・写真 | ライブ一覧 |
| `MEMBERS` | プロフィール | メンバー一覧 |
| `MUSIC` | 楽曲・歌詞・音源 | 楽曲一覧 |
| `EXTRAS` | お楽しみ | クイズ・おみくじ・企画 |
| `HAUNTED HOUSE` | お化け屋敷 | 閉鎖中のお化け屋敷 |

### その他のナビゲーション

| 英語見出し | 日本語補助表記 |
|---|---|
| `I LOVE BLETH` | FAN CLUB |
| `LINKS` | 関連リンク |

スマートフォンのメニューボタンは `MENU`、閉じるボタンは `CLOSE` とする。アイコンだけにせず、文字ラベルを併記する。

## 4. トップページ

トップは遊園地マップだけで構成し、マップ内の各アトラクションをリンクとして使用する。背景とアトラクションを別画像にし、現行のBLETHLANDロゴ画像を重ねる。重複するカードやフッターは置かない。マウスオン時は対象アトラクションだけを明るくし、四角い白枠は表示しない。

画像左上の `HISTORICAL ARCHIVE` は表示しない。右上には画像内文字を使わず、次の文字列をHTMLテキストとして重ねる。

```text
LAST UPDATED 2004.08.29
```

下層ページのヒーロータイトルは、背景のアトラクションが見えるコンパクトなサイズと高さで統一する。

## 5. LIVE

ページ見出し:

```text
LIVE
ライブ情報
```

リード文:

```text
これからの予定: `現在、ライブの予定はありません。`

これまでのライブを、日付・会場・写真とともに紹介します。
```

一覧の表示項目:

- 日付
- 公演名
- 会場
- 写真の有無

操作ラベル:

- `ライブの詳細を見る`
- `写真を見る`
- `前のライブ`
- `次のライブ`
- `LIVEへ戻る`

メンバーコメントには、次の見出しを付ける。

```text
COMMENT
メンバーコメント
```

## 6. MEMBERS

ページ見出し:

```text
MEMBERS
プロフィール
```

リード文:

```text
BLETHのメンバーを、担当と名前で紹介します。
```

全メンバーをこの1ページにまとめ、個別プロフィールページは作らない。カードまたはページ内アンカーで、次の項目だけを表示する。

プロフィールカードの項目:

- 名前
- パート

メンバー写真と紹介文は掲載しない。

操作ラベル:

- `MEMBERSへ戻る`

誕生日、血液型、身長、体重、足のサイズ、視力、愛車、住所・地域、勤務先、家族・ペット、恋愛、私生活上の好みは掲載しない。当時の悪ノリや内輪向けの冗談も削除する。

人数は、旧トップの「6人組」と現存する5人分のプロフィールの不一致が解決するまで本文に記載しない。

## 7. MUSIC

ページ見出し:

```text
MUSIC
楽曲・歌詞・音源
```

リード文:

```text
BLETHの楽曲を、歌詞、クレジット、コメントとともに紹介します。
公開可能な音源がある楽曲は、このページで再生できます。
```

楽曲カードの項目:

- 曲名
- 作詞・作曲クレジット
- 歌詞
- 音源
- メンバーコメント

操作ラベル:

- `楽曲の詳細を見る`
- `歌詞を見る`
- `音源を再生`
- `一時停止`
- `前の楽曲`
- `次の楽曲`
- `MUSICへ戻る`

音源を掲載しない場合:

```text
この楽曲の音源は現在公開していません。
```

`ORIGINAL SONGS`、`オリジナル曲`、`試聴するにはRealPlayerが必要です`は使用しない。

## 8. 旧SHOWS

公演情報は `LIVE` の「これまでのライブ」へ統合する。旧 `/shows/` は `/live/` へ転送し、独立したナビゲーション項目は置かない。

## 9. EXTRAS

ページ見出し:

```text
EXTRAS
お楽しみ
```

リード文:

```text
バイキングに集まった、BLETHLANDならではの3つの企画をご案内します。
```

コンテンツラベル:

| コンテンツ | 見出し | 操作ラベル |
|---|---|---|
| BLETHクイズ | `BLETH QUIZ` | `現在閉鎖中`（リンクなし） |
| おみくじ | `BLETHLAND FORTUNE` | `現在閉鎖中`（リンクなし） |
| GLAYコピーバンド企画 | `SPECIAL EXHIBIT` | `現在閉鎖中`（リンクなし） |

入力や抽選結果に関する共通注記:

```text
入力内容や結果は保存・送信されません。
```

第三者情報の確認が終わっていない展示には、次の表示を使う。

```text
この展示は現在準備中です。
```

### お化け屋敷の画像方針

旧ページ内の人物写真 `web_illust_jpg/ghost01.jpg`、`ghost02.jpg`、`ghost03.jpg` は、プライバシー保護のため非公開とする。公開ディレクトリへコピーせず、サムネイル、ぼかし、切り抜き、生成AIへの参照にも使用しない。

お化け屋敷はEXTRASから分離し、トップから単独ページへリンクする。単独ページにはアトラクションイラストと `現在閉鎖中` だけを表示する。

## 11. LINKS

ページ見出し:

```text
LINKS
関連リンク
```

リード文:

```text
BLETHに関連する、現在確認できるリンクを掲載します。
```

リンクカードの項目:

- サイト名
- 関係・説明
- 外部サイトであることの表示

操作ラベル: `外部サイトを開く`

外部リンク注記:

```text
外部サイトの内容は、BLETHLANDが管理するものではありません。
```

確認できるリンクがない場合:

```text
現在掲載している関連リンクはありません。
```

原本の管理人名、募集情報、リンク切れURLは自動的に再掲載しない。

## 13. 共通UI文言

| 用途 | 使用する文言 | 使用しない文言 |
|---|---|---|
| 一覧へ戻る | `一覧へ戻る`、`MUSICへ戻る`など | `Back`、`back` |
| 詳細リンク | `ライブの詳細を見る`など | `詳細はこちら`、`↑クリック！` |
| 音源 | `音源を再生` | `BLETHの歌を聴こう!!` |
| メニュー | `MENU` | `INFORMATION` |
| 楽曲 | `MUSIC`、`楽曲` | `ORIGINAL SONGS`、`オリジナル曲` |
| 公演 | `SHOWS`、`公演情報` | `公演記録`、`もう終わってしまったLIVE` |

## 14. 404ページ

ページ見出し:

```text
404 — LOST IN BLETHLAND
```

本文:

```text
お探しのページは見つかりませんでした。
ゲートへ戻って、別のアトラクションをお楽しみください。
```

操作ラベル: `BLETHLANDのトップへ戻る`

## 15. 実装時の確認事項

初期実装では、次の未確定情報をコピーに含めない。

1. メンバーの人数。
2. CDの現在価格と購入方法。
3. 現在のライブ予定とチケット販売。
4. ファンクラブの現在の運営状況。
5. 未確認の外部リンク。
6. 公開許可を確認していない第三者情報。BLETHの歌詞と音源は公開可能。

これらが確認できた場合も、第三者情報とBLETHの公式案内を同じ表示領域に混在させない。

お化け屋敷の人物写真以外の旧サイト内写真は原則掲載可能とする。ただし、公開用に複製する際はEXIFなどの付帯メタデータを除去する。
